# debugging-exercise
Fixing a Basic Event-Driven Webpage

Objective

At the end of the exercise, students should be able to identify and correct common HTML and JavaScript errors, use
the browser console to locate syntax and runtime errors, properly attach event listeners and handlers, and test whether
an event-driven webpage functions correctly.

Activity Description

The following webpage contains several errors that prevent some of its features from working correctly. Use the
browser Developer Tools and Console to identify and correct the errors.
The completed webpage should:
 Display a personalized greeting when the button is clicked.
 Show a message while the user is typing.
 Change the webpage background color.
 Reset the webpage to its original state.
 Display debugging messages in the browser console.
 Run without console errors.
